# CHANGELOG

Общего журнала в корне нет: у инструментов независимые версии и теги (`<инструмент>-vX.Y.Z`),
поэтому история изменений ведётся в каталоге каждого инструмента. Этот файл — указатель: строка
в таблице появляется, когда в репозитории добавляется новый инструмент (чеклист — в
[CONTRIBUTING.md](CONTRIBUTING.md)).

| Инструмент | История изменений |
| --- | --- |
| `cio` — Container image optimizer | [Container image optimizer/CHANGELOG.md](Container%20image%20optimizer/CHANGELOG.md) |
| `sqlbrc` — SQL backup restore clone | [SQL backup restore clone/CHANGELOG.md](SQL%20backup%20restore%20clone/CHANGELOG.md) |

Формат разделов — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация версий —
[SemVer](https://semver.org/lang/ru/); правила версионирования и порядок релиза — в
[CONTRIBUTING.md](CONTRIBUTING.md), состав инструментов — в [README.md](README.md), политика
безопасности для всех инструментов — в [SECURITY.md](SECURITY.md).
