# Container image optimizer

## Суть
- анализирует Docker-образы, показывает размер слоёв, устаревшие пакеты, предлагает multi-stage сборку и уменьшение размера.

## MVP
- CLI, который выдаёт отчёт по образу.

## Стек
- Go + Docker API + Trivy.

## Польза
- ускорение деплоя и экономия места в registry.
